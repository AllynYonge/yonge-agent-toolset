# 人物与历史长文

先整理时间线，再分清三件事：
1. **先后**：只说明两件事按时间顺序发生；
2. **因果**：说明前一件事确实促成了后一件事；
3. **动机**：说明人物确实因为某个特定想法才采取行动。

来源材料只支持先后顺序时，严禁使用"于是"、"因此"、"这促使他决定"强行拼凑因果。来源没有人物自述记录时，绝不替他虚构内心独白。

资料能证明人物做过具体选择，才写选择。资料只证明他离开一家公司、搬去另一座城市，就平实记录动作、当时面临的现实条件和后来的客观结果。后来的成功，绝不能倒过来证明他早年的每一步都富有远见。

戏剧性张力来自确有记录的现实变动：收入中断、技术路线走不通、合作破裂、行业规则改变、资金和人力短缺，或者一个记录在案的决定所带来的不可撤回后果。不能把每一次常规升学、搬家和换工作都渲染成命运押注。历史长文的真实压力往往早已蕴含在地理、兵力、制度、可选道路与失败后果之中，讲清楚这些客观条件，人物的处境自然会凸显出来。

来源没有记录天气、神态、房间陈设、现场对白与心理活动，一律不予脑补添加。资料不足时，补充经过多方核准的时代与行业背景，或者主动缩短文章篇幅。时代背景和个人履历只在直接改变人物选择条件时才展开；如果学校、职位与城市罗列了一大堆，人物仍然没有任何具体动作，说明文章还停留在简历拼贴阶段。

## 标题选型

标题的句式与检查清单见 `references/craft/title.md`，这里只写人物特稿与历史长文的选型偏好。

- 一类优先：具体抉择型或时代截面型。说明白人物在什么具体危机节点做出了什么决定，或者大时代背景如何落在一个具体人的账本上。次要可用因果落差型。
- 关键词：具体人物身份加上标志性动作，或历史年份加上转折事件。
- 拒绝造神与标签化：严禁使用"商业奇才"、"一代枭雄"、"逆袭神话"等空泛形容词。

示例：

- "老周的最后一次搬家：一家修车铺与一家人的十五年"（具体动作 + 真实切口）
- "一九九三年，深圳那间没有空调的库房与一次未被记录的抉择"（时间地点 + 客观悬念）
- "退无可退的决战：重读某某企业在二零零八年的至暗时刻"（真实压力 + 关键节点）

## 开头模板

人物与历史长文开头核心：**3句内定格一个真实有据的物理时空，杜绝宏大空泛的抒情**。

### 开头模式1：历史截面定格型

**行文路径：** 给出极其确切的时间、地点与一件微小的具体实物/账单→带出人物当时所处的逼仄条件

**完整示例：**
> 一九九八年十月的一个下午，三十七岁的张建把办公室钥匙留在了门卫室。
> 按照破产清算协议，这栋两层砖房将在下周一被贴上封条。
> 账面上剩下的两万三千块钱，刚好够给车间的最后八名老员工发完当月的安置费。

### 开头模式2：关键动作入场型

**行文路径：** 以人物一个真实发生的标志性动作为切入点→还原做出该动作时的现实阻碍

**完整示例：**
> 调令送到桌上的时候，老周正在排查第三条生产线上的线路故障。
> 工厂下个月就要全部迁往外省，摆在他面前的选择只有两个：要么跟着搬迁，要么签字拿补偿金走人。
> 他洗干净手上的机油，在车间走廊里站了很久。

### 开头模式3：当下现实回望型

**行文路径：** 先平实交代当下的庞大规模或历史结果→随即翻回早年极其简陋的真实起点→形成客观对照

**完整示例：**
> 如今这家拥有上万台服务器的量化投资机构，最早的代码是在一间不到十平米的合租房里写出来的。
> 当时没有高薪团队，也没有充足的算力支持，唯一的固定设备是一台二手台式电脑。
> 两个创始人在白天各有一份全职工作，真正开始调试策略，只能等晚上十点以后。

## 正文模板

人物与历史长文最忌"流水账履历"和"事后诸葛亮式的神化描写"。正文推进应当始终以客观条件、现实阻碍和人物动作为主线。

### 结构一：时序编年与关键拐点型（经典人物特稿 / 商业兴衰传记）

- **适用场景：** 跨越数年或数十年的完整人物生平、企业发展史或行业演进史。
- **大框架：**
  - 第1部分：最初起点与受限条件（当时手头有什么资源、什么负担，没有神仙指导）
  - 第2部分：第一次摸索突破（摸清行业门道，解决生存问题，形成早期的能力底座）
  - 第3部分：不可抗力的外在规则巨变（技术革新、政策调整、资本潮退或市场饱和带来全面危机）
  - 第4部分：关键拐点的生死决断（有据可查的痛苦抉择，放弃了什么、换取了什么代价）
  - 第5部分：新平衡的建立与晚期代价（成功的另一面是无法挽回的遗憾或被时代推向边缘）
- **细脉络设计（每个阶段怎么写）：**
  - **现实条件：** 年龄、账本资金、家庭负担、行业当时的规则与门槛
  - **具体动作：** 面对困难他究竟迈出了哪一步，换了什么办法
  - **客观结果：** 市场、制度或现实给予的真实反馈，不拔高意义
- **小标题设计原则与参考形态：**
  - **核心原则：** 采用"时间阶段 + 具体的生存处境"，严禁使用"初露锋芒"、"走向辉煌"等八股修辞。
  - **参考形态：**
    - 阶段处境型："一九九八：在小作坊里解决不会报价的麻烦"
    - 危机抉择型："搬迁令下达：留下来比走出去更需要勇气"
    - 规则洗牌型："风口过去之后：算清账本才能活下来"
  - **反面示范：** "第一章：艰难岁月"（空泛抒情）、"事业巅峰"（缺乏事实细节）

### 结构二：重大危机与生死抉择型（历史切片 / 至暗时刻深度复盘）

- **适用场景：** 聚焦单一重大历史事件、企业破产边缘或核心战略转折期（集中在几周或几个月内）。
- **大框架：**
  - 第1部分：危机爆发的现场态势（资金链即将断裂、核心骨干出走或监管红线突降）
  - 第2部分：旧解法全面失灵（曾经管用的套路为何在这次危机中加速了恶化）
  - 第3部分：多方博弈与筹码称重（资方、对手、团队、监管各自的诉求与底牌）
  - 第4部分：最终艰难落子（在所有糟糕的选择中，选了一个代价可承受的方案）
  - 尾段：尘埃落定与长远遗存（这场风波留下的永久制度烙印或组织伤痕）
- **细脉络设计（每个博弈环节怎么写）：**
  - **各方底牌：** 谁能承受多久的消耗，谁握有一票否决权
  - **信息差与误判：** 当时当刻真实掌握的情报边界（承认不知道的事情）
  - **落子代价：** 没有完美的双赢，写清谁承担了最终代价
- **小标题设计原则与参考形态：**
  - **核心原则：** 聚焦"博弈各方的核心诉求与倒计时节点"。
  - **参考形态：**
    - 倒计时型："账面资金只剩最后两周"
    - 筹码对峙型："董事会里的无声对决：谁掌握最终签字权"
    - 代价落地型："签下协议的那天：交出控制权换取企业存活"
  - **反面示范：** "危机的爆发"（平淡）、"力挽狂澜"（自我神化）

### 结构三：历史群像与时代横切面型（行业生态 / 时代微观切片）

- **适用场景：** 一次宏观变革（如产业外迁、技术颠覆、监管新规）下，不同生态位角色的命运分化。
- **大框架：**
  - 第1部分：宏观潮水转向（客观交代某项关键制度、技术或供求关系的结构性改变）
  - 第2部分：第一类角色（顶层决策者/资本方：他们的顾虑、权衡与战略转移）
  - 第3部分：第二类角色（中层执行者/中小创业者：在夹缝中拼命调整业务姿势）
  - 第4部分：第三类角色（底层从业者/普通家庭：最直接承受成本与转岗阵痛）
  - 尾段：潮水退去后的真实地貌（不同角色的生存结局汇聚成时代印记）
- **细脉络设计（每个角色切片怎么写）：**
  - **不同视角的账本：** 同样一项政策，对谁是利好，对谁是无法承担的支出
  - **微观处境对抗：** 拒绝写成统计数字，写出具体人在一个工作日的实际作为
- **小标题设计原则与参考形态：**
  - **核心原则：** 以"具体角色 + 他们眼前的账本"命名，形成多维互映。
  - **参考形态：**
    - 角色账本型："厂长的计算器：搬迁补贴能撑过几个季度？"
    - 基层抉择型："老工人的铺面：三十七岁重头学习修电动车"
    - 产业链观察型："下游供应商的结账日：被延期的汇票与空转的厂房"
  - **反面示范：** "大时代下的小人物"（套路标签）、"群像描写"（缺乏主体）

### 正文表达手法与纪实规范

| 维度 / 场景 | 推荐手法 | 严禁行为 |
|---|---|---|
| 经历陈述 | 动作 + 客观条件 + 后果 | 严禁添加未记录的心理独白与天气神态 |
| 资料缺口 | 主动交代记录边界，收住笔墨 | 严禁为了戏剧张力凭空捏造私下谈话 |
| 因果分析 | 事实材料证明因果才写因果 | 严禁把先后的时间顺序包装成必然因果 |
| 时代背景 | 仅展开直接改变人物条件的制度与经济背景 | 严禁脱离人物行动大篇幅摘抄通史背景 |

## 结尾模板

人物与历史长文结尾核心：**把结论留给事实后果，绝不要在文末升华主题或强行煽情**。

### 结尾模式1：动作余波定格型

**行文路径：** 停留在人物晚年或事件平息后，一个具体、平静、日常的真实状态

**完整示例：**
> 退休后的老周很少再去车间，他的铺面交给了一个年轻徒弟打理。
> 天气好的时候，他习惯坐在铺子门前看街上往来的电动车。
> 当年厂区的那块地皮，现在已经建成了高耸的住宅小区，只有街角那棵老槐树还在原来的位置。

### 结尾模式2：评价克制留白型

**行文路径：** 平实陈述当事人的最终客观去向与行业当时留下的制度记录，不做高调盖棺定论

**完整示例：**
> 商业上的成败往往很难用一句话概括。
> 他留下的这套调度系统，在后续十几年里依然支撑着整座城市的物流运转。
> 当年关于那笔并购案的争议慢慢淡去，只有档案室里那本厚厚的交接记录，依然按年份整齐摆放在那里。

### 结尾模式3：现实回望对照型

**行文路径：** 从历史现场拉回当下，用当下的平凡生活对照历史尘埃中的惊心动魄

**完整示例：**
> 今天在各大证券大楼里忙碌的年轻交易员，很少有人知道三十年前那套简陋程序的来历。
> 市场依然每天开盘、跳动、结算。
> 风险没有减少，博弈没有停歇，只是换了一代又一代坐在屏幕前的人。

## 金句与史观提炼模板

历史特稿金句核心：**重在因果的沉重与代价的真实，不讲鸡汤大道理**。

1. **代价型：** 所有的选择都有代价，当时的___，是用后来的___换来的
   - 所有的选择都有代价，当时守住的体面，是用后来长达十年的清贫换来的
2. **因果型：** 不是因为___才走向成功，而是身处___之中别无选择
   - 不是因为他早早看清了行业趋势，而是当时的退路被彻底切断，只能硬着头皮走到底
3. **时代型：** 大时代的风浪落在一个家庭的账本上，往往只是___
   - 宏观产业变迁落在一个普通工人的账本上，往往只是一笔还未还清的车贷
4. **事实型：** 真正决定命运的往往不是___，而是那次看似平常的___
   - 真正决定生死的往往不是发布会上的掌声，而是危机当晚那笔准时到账的过桥资金

## 原创示范

下面的片段均为虚构，只示范客观说话关系和推进方式。不能把其中的人物、数字和经历拿去冒充事实。

### 示范1：人物经历平着讲

> 老周辞职那年已经三十七了。他没有什么远大计划，只是原来的工厂搬去了外省，留下的人要么跟过去，要么拿补偿走。
>
> 他家里有老人，孩子刚上初中，搬家这条路很难走。补偿款一到账，他先还了车贷，又在小区门口盘下一间修电动车的小铺。以前他在厂里管设备，拆电机算老本行，修车却要直接面对顾客。头两个月最难的也在这里，他会修，不会报价，经常忙一下午只收二十块。
>
> 后来他学会先问故障，再把要换的零件摆在台面上。生意慢慢稳下来。这个变化写进履历很小，对他家却很要紧，他终于不用去外省了。

**示范评析：**
张力来自年龄、家庭负担、资金现实和不会报价的窘迫。完全没有把一次被迫的离职加工成轰轰烈烈的“命运决战”，平实反而极具质感。

### 示范2：资料不足时收住笔墨

> 公开材料能确认两件事。他毕业后离开了原公司，后来去了成都继续做量化。至于这两步之间有没有一次很戏剧化的谈话，现在找不到可靠记录。
>
> 这不妨碍故事往下讲。当时他手里的条件已经变了。程序跑过一段时间，国内能使用的交易工具也在增加，他可以把原本放在工作之外的研究拿到白天来做。风险很清楚，收入会断，结果每天由市场给。
>
> 写到这里已经够了。人确实离开了，量化也确实成了全职工作。那天有没有下雨，他关门时想了什么，我们不知道。

**示范评析：**
严谨不需要通篇声明，只在会改变人物评价的关键事实缺口处交代一次。不凭空猜测天气与心理，克制展示已知事实。
