# 个人叙事

先找最清楚的动作、物件、场景与一次意外。保留当时的理解，也保留今天回头看的变化。

物件前后出现时，现实作用和后来含义都要成立。不要为了首尾呼应凭空造一只杯子、一张车票或一封旧信。

## 个人成长文

框架、开头、结尾的通用写法见 `references/craft/structure.md` 与 `references/craft/hooks.md`，素材见 `references/craft/material.md`。

个人成长文讲作者在某件事上的经历、挫折、发现和改变，让读者认识这个人、信任这个人。经历必须是用户提供或确认过的，缺的部分问用户，不替用户编。

## 标题选型

标题的句式与检查清单见 `references/craft/title.md`，这里只写个人成长文的选型偏好。

- 一类优先：身份锁定型。成长文让人点开的理由通常是"这个人跟我处境相近"。次要可用展示回报型。
- 关键词：身份词加数字，或身份词加反差词。数字给过程一个刻度，反差给结果一个落差。
- 可兑现：标题里的身份和时间跨度必须对应正文真实经历过的阶段，没有的阶段不写。
- 避开：用"宝妈""打工人"这类身份词却讲不出该身份的处境，以及只有结果没有过程的标题。

示例：

- "从月薪3000到月入2万：一个普通宝妈的真实故事"（身份锁定 + 数字）
- "辞职500天后，我终于不再害怕没有稳定收入"（身份锁定 + 数字）

## 开头模板

IP成长文开头核心：**3句内进入真实故事**。不要寒暄，不要铺垫，直接进场景。

### 开头模式1：场景代入型

**行文路径：** 用一个具体的"那个时刻"开场→描述当时的处境→引出你要讲的故事

**完整示例：**
> 2019年12月31日，跨年夜。
> 别人在放烟花，我坐在出租屋里盯着手机——公众号后台粉丝数：127。
> 那是我做公号的第8个月。
> 我想不通，为什么我这么努力，还是没人看？

### 开头模式2：决定时刻型

**行文路径：** 直接说出你做的那个关键决定→描述决定前的状态→引出"这个决定之后发生了什么"

**完整示例：**
> 2020年3月，我做了一个所有人都反对的决定：辞掉国企的工作，全职做公众号。
> 当时我妈气得三天没理我。
> 但我知道，再不走，我会被这份工作耗死。

### 开头模式3：反差切入型

**行文路径：** 先展示"现在的状态"→再翻回"之前的状态"→制造反差，引出故事

**完整示例：**
> 现在的我，靠写公众号月入2万，读者10万+。
> 但两年前，我是那个写了8个月阅读量不过百的人。
> 今天想讲讲这两年到底发生了什么。

## 正文模板

个人成长文最忌"只讲成功不讲失败"。失败与脆弱才是引发共鸣的关键。无论采用哪种结构，都要写出真实的心理变化。

### 结构一：英雄之旅型（蜕变重构 / 经典破局）

- **适用场景：** 长周期的重大蜕变、创业或转型经历、从迷茫低谷到破局重生的完整故事。
- **大框架：**
  - 第1段：初心目标（想做什么？为什么出发？）
  - 第2段：现实阻碍（遇到了什么具体困难与瓶颈？）
  - 第3段：自救行动（采取了哪些具体方法来克服？）
  - 第4段：初步结果与意外危机（发生没想到的波折，引发危机）
  - 第5段：认知转折（意外事件带来的顿悟时刻）
  - 第6段：当前结局与价值沉淀（现在的状态，给读者的启发）
- **细脉络设计（每个阶段怎么写）：**
  - **事实：** 发生了什么（具体场景、具体时间、具体数字与动作细节）
  - **感受：** 当时怎么想（真实脆弱的情绪，不怕暴露短板）
  - **反思：** 现在怎么看（以当下成熟视角复盘，给出认知升级）
  - *关键提醒：* 英雄之旅的灵魂是“真实与脆弱”。失败和困惑才能引发共鸣，切忌写成一路开挂的流水账。
- **小标题设计原则与参考形态：**
  - **核心原则：** 必须体现“心境变化”与“命运转折点”，具备故事张力与情绪起伏，严禁使用纯名词分类。
  - **参考形态：**
    - 回忆场景型："那时候，我还在___"、"起点：兜里只有___块钱的日子"
    - 危机转折型："转机出现在___"、"突如其来的意外，打碎了所有计划"
    - 顿悟升级型："我终于明白了___"、"那一刻我才懂：真正的___不是___"
  - **反面示范：** "一、我的创业经历"（缺乏故事感）、"遇到的困难"（平铺直叙、无情绪张力）

### 结构二：时间线演进型（里程碑演进 / 阶段盘点）

- **适用场景：** 年龄阶段回顾（如20/25/30岁）、从业周年盘点（如辞职500天、入行10年）、多阶段能力跃迁。
- **大框架：**
  - 第1段：当前节点切入与回望由头（如"辞职500天后的今天"）
  - 第2段至第N段：精选 3~4 个关键演进节点（每个节点遵循“遇到问题 → 做出选择 → 得到结果”）
  - 尾段：回望起点，收束当下认知，给同行者鼓励
- **细脉络设计（每个阶段怎么写）：**
  - **节点刻度：** 明确的具体时间或年龄节点
  - **关键事件与抉择：** 当时做了什么重要决定、付出了什么代价
  - **阶段顿悟：** 这一阶段留下的核心教训
- **小标题设计原则与参考形态：**
  - **核心原则：** 采用“时间/阶段 + 心态/状态”的复合句式，让读者仅看标题就能感知主角在不同阶段的成长轨迹与心态变迁。
  - **参考形态：**
    - 阶段状态型："二十五岁：什么都不懂，但什么都不怕"
    - 打击成长型："二十八岁：第一次被打脸，学会向现实低头"
    - 清醒成熟型："三十一岁：终于知道自己要什么"
    - 时间刻度型："辞职第100天：焦虑与自由并存"、"辞职第500天：接纳不确定性"
  - **反面示范：** "第一阶段（2018-2020）"（像履历表汇报）、"大学毕业后"（缺乏心态描绘）

### 结构三：困境决战型（危机对撞 / 关键选择）

- **适用场景：** 遭遇单一重大突发危机、关键十字路口的人生抉择（如裸辞、负债、断崖式失业）。
- **大框架：**
  - 第1段：直接切入高压危机现场（极限拉扯的真实场景）
  - 第2段：剖析两难困境（进退维谷的根本原因与内心博弈）
  - 第3段：破局抉择与代价承担（为什么选这条难走的路？）
  - 第4段：摸索执行与脱困实操（做对了哪几件关键动作）
  - 尾段：危机过后的认知洗礼与长效启示
- **细脉络设计（每个环节怎么写）：**
  - **高压情境：** 具体的时间、账单、对话与生理感受（如手抖、失眠）
  - **内心博弈：** 两种选择各自的恐惧与代价
  - **破局逻辑：** 是什么关键认知促成了最终行动
- **小标题设计原则与参考形态：**
  - **核心原则：** 聚焦“内在冲突”与“破局行动”，直面两难抉择的压力，避免轻描淡写。
  - **参考形态：**
    - 冲突对立型："摆在面前的两条路：退缩还是硬扛？"
    - 绝地破局型："最难的那一晚，我做了人生最冒险的决定"
    - 代价收获型："那些杀不死我的，变成了___"
  - **反面示范：** "克服困难的过程"（过于平淡）、"关于选择的思考"（说教感重）

### 正文表达手法使用建议

| 位置 / 内容 | 推荐手法 | 原因与效果 |
|---|---|---|
| 开头场景 | 举例 + 细节 | 让读者"看见"当时的具体处境 |
| 阻碍段落 | 对比 + 数据 | 把困难具体化，例如"做了100次只成功1次" |
| 转折节点 | 转折 + 因果 | "正是这次意外，让我发现了关键转机" |
| 感悟升华 | 引用 + 类比 | 用书籍观点或名人格言，为个人感悟找到理论支撑 |
| 结尾收束 | 排比 + 提问 | 用排比句强化行文节奏，用提问引发读者互动 |

## 金句模板

IP成长文金句核心：**有真实感，有温度，像跟朋友说的话**。

1. **真实型：** 我用了___才发现___
   - 我用了两年才发现，赚钱的关键不是更努力，是更聚焦
2. **反差型：** 以前我觉得___，现在我明白___
   - 以前我觉得失败是丢人的，现在我明白失败是唯一的路
3. **劝告型：** 如果你正在___，记住___
   - 如果你正在低谷，记住：所有的转折都是在最低点开始的
4. **共鸣型：** ___的时候，是最___的时候
   - 想放弃的时候，是最接近突破的时候
5. **接受型：** 我不再___了，因为___
   - 我不再追求完美了，因为完成比完美重要一百倍
6. **节奏型：** ___不是一天完成的，是一天一天完成的
   - 成长不是一天完成的，是一天一天完成的
7. **对比型：___的人看___，___的人看___**
   - 焦虑的人看结果，踏实的人看过程
8. **行动型：别等___了，___就是最好的时机**
   - 别等准备好了，开始就是最好的准备

### 参考范例

#### 范例1

**标题：** 从月薪3000到月入2万：一个普通宝妈的真实故事

**开头原文：**
> 2019年6月，我坐在客厅地板上，手机余额提示：银行卡余额247块。
> 孩子在旁边玩积木，老公刚打来电话说又要加班。
> 那是我做公众号的第4个月，写了30多篇文章，粉丝不到200。
> 我想哭，但又不敢让孩子看到。

#### 范例2

**标题：** 辞职500天后，我终于不再害怕没有稳定收入

**开头原文：**
> 辞职那天，我发了条朋友圈："自由了。"三个字，13个赞。
> 没人知道我手在抖。
> 因为下个月的房贷、车贷、孩子的学费，一分都不会少。
> 500天后的今天，我想说说这500天到底发生了什么——真实的、不那么光鲜的那种。
