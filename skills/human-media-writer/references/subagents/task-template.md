## Agent 选择

- **职责要求**：[通用推理 / 只读探索 / 写入执行 / 独立审核 / 外部研究 / 其他]
- **权限要求**：[只读 / 可写；可联网 / 禁止联网；允许 / 禁止再次委派；其他]
- **硬性平台要求**：[独立上下文 / 必须支持续接 / 必须强制限制工具或权限 / 无]
- **优先选择**：职责和权限均满足的现有 Agent
- **可接受降级**：[通用 Agent + 完整任务提示词 / 由主代理执行并声明降级 / 不允许降级]
- **禁止选择**：[不满足独立性、权限、工具或结果获取要求的 Agent]

Agent 名称由平台适配器根据当前工具实际列表确定；任务说明只写能力要求，不把某个平台的角色名当作跨平台名称。

### 派发

- 一次发送完整、已填充的任务提示词（默认）
- [其他派发约定]

### 执行中

- 子代理回问：禁止（默认）
- 主代理追加指令：禁止（默认）/ 允许时写：[触发条件；消息必须包含的内容；不得改变任务目标或扩大任务范围]

### 结果验收后

| 结果形态 | 主代理动作 |
|----------|------------|
| 格式不全 | 平台支持针对原 ID 触发续接时，补充一次缺失内容 → 不支持续接或补后仍不符合 → `result_invalid` |
| [任务成功] | [交回业务流程 / …] |
| [主代理需要继续处理] | [处理动作，或 → 主代理闭环] |
| `ERROR` / 调度失败 | 按 `protocol.md` 处理；不计入执行次数（若任务定义了哪些结果计入执行次数） |

### 主代理闭环（可选）

主代理闭环是指：主代理处理子代理结果后，再创建新的子代理任务继续下一步。仅在「结果验收后」需要这样处理时填写；否则整节省略。

- **进入**：[条件]
- **不进入**：[条件]
- **单轮**：
  1. [如何使用子代理结果]
  2. [哪些内容可自主处理，哪些需要用户确认]
  3. [创建新任务：只传递什么 / 禁止传递什么]
- **终止**：[条件表]
- **计入执行次数的结果**：[引用「结果验收后」或直接说明]
- **约束**：[必须遵守 / 禁止]
- **结束后输出**：（可选）[摘要格式]
- **流程**：（可选）mermaid 或步骤列表
