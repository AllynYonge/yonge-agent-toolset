# 无子代理工具时的备用规则

当前环境没有可靠的运行时子代理能力，或动态接口不能满足任务硬要求时使用。  
不模拟、不伪造子代理。

## 何时使用

- 没有创建子代理的工具  
- 无法可靠等待或取得子代理结果  
- 不能满足要求的上下文独立性  
- 任务要求平台强制的权限、工具或隔离限制，但动态接口只能提供提示词行为约束  
- 任务要求续接原子代理，但平台既不返回可复用 ID，也不提供续接能力  
- 没有匹配的平台规则，或专用规则声明不适用  

## 能力差异

| 能力 | 本平台 |
|------|--------|
| 创建 / 等待 / 停止 / 关闭 | 不支持或不可靠；主代理按任务备用方式执行或声明无法完成 |
| 续接 / 中途回问 | 不支持；由主代理按备用方式一次性执行或声明失败 |
| 权限与隔离 | 不伪造动态子代理的权限边界；主代理只能在自身现有权限内执行备用方式 |
| 依赖文件 | 同 protocol；主代理直接完整读取 |

## 主代理可代替时

任务说明允许“由主代理执行”时：

1. 使用同一份已填充任务提示词。  
2. 只使用任务允许的信息，忽略无关会话历史。  
3. 遵守任务提示词中的行为限制，并受主代理当前实际权限约束。  
4. 按原输出格式返回，不省略结果验收。  
5. 只呈现业务结果，不必展示内部备用过程；任务要求披露备用状态时如实标记。  

## 主代理不可代替时

同时满足则不得假装完成：

- 明确要求真正独立的第二视角  
- 主代理已参与该任务的产出或修改  
- 任务不允许主代理备用  

→ 说明当前无独立子代理能力，`delegation_unavailable`。Never 声称结果来自独立子代理。

## 不得采用的伪备用方式

- 不在提示词中扮演“第二个 Agent”并声称获得独立视角。  
- 不通过输出 `@agent` 文本模拟程序化委托。  
- 不通过 shell、配置修改或临时创建 Agent 定义绕过平台权限或动态接口限制。  
- 不创建一个新的普通任务冒充对原子代理的续接。  

## 依赖文件

- 标记“必须完整读取”的必须完整加载。  
- 无法取得 → `resource_unavailable`。  
- Never 凭记忆补全规则或事实。
