# OpenCode 子代理委派规则

完成上一级 `protocol.md` 的委派步骤。本适配器只处理主代理通过运行时工具进行的动态委托，不为单次任务创建或修改 Agent 配置。

## 何时使用

- 当前环境是 OpenCode，且主代理实际提供 `Task` 或等效 subagent 调用工具。
- 用户输入中的 `@agent` 是手动调用入口，不作为主代理编排时模拟调用的备用方式。
- 否则改用 `generic.md`。

## 能力差异

| 能力 | OpenCode |
|------|----------|
| 创建 | 主代理用 `Task` 调用当前工具描述中可用的 subagent |
| 等待 | Task 同步返回时直接取得结果；异步行为以实际返回为准 |
| 补充 / 续接 | 仅返回可复用 session / task ID 且环境明确提供继续调用能力时可用 |
| 关闭 | Task 同步返回后视为本次调用结束；无显式关闭能力时不构造调用 |
| 上下文 | subagent 使用独立 child session；任务提示词必须自包含 |
| 依赖文件 | 同 protocol；传可读取路径，不可读则完整内联 |
| 权限 | `permission.task` 控制可调用的 subagent；新配置优先使用代理级 `permission` |
| 子代理类型 | 仅使用当前 Task 工具实际列出的类型及描述 |

## 委派映射

| 委派步骤 | 动态处理 |
|----------|----------|
| 派发 | `Task` + 实际可用 subagent + 已填充任务提示词 |
| 保存 ID | 有 child session / task ID 时保存；否则保存任务 ID 与调用记录 |
| 等待 / 取结果 | 同步时直接使用 Task 返回的最终内容；异步时按实际能力等待原 ID |
| 补充 | 仅存在针对原 session / task 的续接能力时使用 |
| 结束 | 同步返回最终内容即视为本次委托结束 |

## 平台特有规则

### 动态选择 subagent

选择前必须读取当前 Task 工具实际列出的 subagent 名称和描述。

根据当前 Task 工具中的描述，判断可用 subagent 是否适合通用执行、本地只读探索或外部资料研究；不依赖文档中的固定内置名称。

- 专业角色、目标、输入、限制和输出格式写入本次 Task 提示词。
- 找不到匹配类型时，不创建定义文件；任务约束允许则使用实际存在的通用类型，否则走备用方式。

### 上下文

- 发送完整、已填充、自包含的任务提示词，包括目标、输入、依赖文件、行为限制和输出格式。
- 不依赖 subagent 知道主会话未传递的信息。
- 当前 Task 接口无法满足任务要求的严格上下文隔离时，走备用方式，不静默降级。

### 权限与递归委托

- `permission.task` 决定当前主代理能看到和调用哪些 subagent；被 `deny` 的类型可能不会出现在 Task 工具描述中。
- 权限模式和匹配顺序以当前平台实际规则为准；动态委托不依赖特定版本的配置细节。
- 若现有配置已禁止子代理再次调用 Task，同时在提示词中说明不得再次委托。
- 动态接口无法修改权限时，提示词限制只是行为约束；严格禁止递归是硬要求时，应选择已受限的现有 Agent，否则走备用方式。
- 权限被拒时不得通过 `@agent`、shell 命令或修改配置绕过。

### 同步返回与续接

- Task 同步返回最终文本时，返回即代表本次动态委托完成；不额外等待、查询或关闭。
- child session 留在会话树中不表示任务仍在运行。
- 只有 Task 返回可复用 session / task ID，且当前环境明确提供针对原 ID 的继续调用能力时，才能补齐验收内容。
- Task 只返回最终文本且无续接能力时，验收失败直接记为 `result_invalid`；不得创建新的 Task 假装续接原 Agent。

## 失败处理

| 情况 | 处理 |
|------|------|
| `permission.task` 拒绝 | 不绕过；可选择另一个已允许且确实满足任务约束的现有 subagent，否则走备用方式 |
| 找不到指定 subagent | 重新核对 Task 工具实际列表；可用通用类型但须满足任务约束，否则 `generic.md` |
| 异步任务等待结束但仍在运行 | `execution_timeout`；保留原 ID，继续等待时仍使用原任务 |
| 结果格式不符 | 能续接原 ID 时只补齐一次；否则 `result_invalid`；Never 重跑完整任务 |

不得遍历不同 Agent 类型来绕过权限，也不得重复处理同一 child session 的结果。
