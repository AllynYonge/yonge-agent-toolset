# Claude Code 子代理委派规则

完成上一级 `protocol.md` 的委派步骤。本适配器只处理运行时动态委托，不为单次任务创建或修改预定义子代理文件。

## 何时使用

- 当前环境是 Claude Code，且实际提供动态子代理创建工具。
- 否则改用 `generic.md`。

## 能力差异

| 能力 | Claude Code |
|------|-------------|
| 创建 | 使用当前会话实际提供的动态子代理创建工具 |
| 等待 | 同步调用返回即完成；后台调用按返回 ID、完成通知或实际任务管理能力处理 |
| 补充 / 续接 | 返回可复用 agent ID 且环境提供消息投递或恢复能力时，联系原子代理 |
| 停止 / 结束 | 仅使用实际提供的停止或关闭能力；无显式工具时不构造调用 |
| 上下文 | 动态子代理通常使用独立上下文；仅运行时工具明确提供继承参数时才可继承 |
| 依赖文件 | 同 protocol；优先传可读取路径，不可读则完整内联 |
| 权限 | 只有运行时调用公开工具、权限或隔离参数时，才能形成平台级强制约束 |

## 委派映射

| 委派步骤 | 处理 |
|----------|------|
| 派发 | 调用当前会话实际存在的动态子代理创建工具 |
| 保存 ID | 返回 agent ID、任务 ID 或名称时立即保存 |
| 等待 | 同步时取工具返回；后台时按原 ID 等通知或用环境提供的查询方式 |
| 补充 | 支持时向原 ID 发送一次只补齐缺失内容的消息 |
| 获取结果 | 工具返回、完成通知或原 ID 续接后的最终内容 |
| 停止 / 结束 | 仍在运行且不再需要结果时才停止；完成后通常视为结束 |

## 平台特有规则

### 动态选择子代理

1. 先看创建工具 Schema 实际公开的可用类型及描述。
2. 有匹配的已注册类型时可选择；否则使用实际存在的通用类型。
3. 专业角色、任务输入、参考文件、行为限制和输出格式全部写入本次任务提示词。
4. 不得为了单次委托临时创建子代理定义，也不得假设某个自定义名称存在。
5. 业务流程不得把 Claude Code 的 Agent 类型名写成跨平台通用名。

### 上下文

| 任务要求 | 动态处理 |
|----------|----------|
| 全新独立 | 使用动态子代理的独立上下文；只发送已填充任务提示词 |
| 最小相关 | 只在任务提示词中传必要背景，不依赖未传递的主会话内容 |
| 继承父会话 | 本动态委托接口不能满足时走备用方式，不借用其它会话分叉能力代替 |
| 无法控制继承 | 不声称满足严格上下文隔离；按任务备用方式处理 |

发送内容必须是完整、已填充、自包含的任务提示词。

### 权限与能力边界

- 提示词中的禁止网络、写文件或再次委托属于行为约束。
- 只有运行时创建调用提供工具白名单、权限模式、隔离或类型参数时，才能把限制落实为平台强制约束。
- 若任务要求严格强制隔离，而动态接口无法满足，走备用方式；不得临时创建定义文件绕过。
- 除非任务说明明确允许，任务提示词必须禁止子代理再次委托；运行时支持限制委托工具时同时收紧。
- 子代理不得运行中向用户澄清；信息须在派发前给齐。

### 前台 / 后台

- 是否同步、后台或立即返回 ID，以本次工具参数和返回值为准，不根据版本默认行为猜测。
- 下一步立即依赖结果时使用同步或等待原 ID；主代理尚有独立工作且工具支持时可后台执行。
- 后台完成通知与主动查询结果须按 ID 去重。Never 因暂无结果而重派。

## 失败处理

| 情况 | 处理 |
|------|------|
| 文档名称与当前工具不一致 | 只使用当前 Schema 实际注册的工具，不尝试历史名称 |
| 创建工具未提供所需隔离能力 | 按任务备用方式处理，不把提示词软约束说成平台强制限制 |
| 无法续接且格式无效 | `result_invalid`；不重新派发完整任务 |
| 后台无完成通知 | 保留原 ID，用环境提供的方式查询一次；无可靠方式则按备用规则处理 |
| 等待结束但仍在运行 | `execution_timeout`；稍后继续等待原 ID |
| 子代理失败 | 不把部分输出当完成结果，除非任务说明允许 |
