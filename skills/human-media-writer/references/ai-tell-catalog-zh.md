# 中文AI痕迹目录

审核子代理使用此目录逐类复查文章，捕捉 P 级摘要规则未覆盖的细粒度信号。这些是质量信号，而非作者身份的证据。人类在压力下也可能这样写作；模型可以避免这些词汇但仍然听起来不自然。将它们视为编辑线索。

## 全局裁决规则

报告任何问题前，先确认：达到条目阈值；不在引用、标题、专有名词或作者标志性表达等保护区域；不属于目标平台、文体或已解析写作风格的正常用法；修改后确实能提升信息或表达，而不会损失真实细节和声音。除 P0 外，孤立的词、标点或句式通常不构成问题，优先寻找模式簇和实质影响。

具体而少见的细节、真实的矛盾情绪、自然插话与自我修正、明确可追溯的个人判断，都是应优先保留的人味信号。Never 为了制造人味而补写不存在的经历、感官细节、犹豫或认知局限。

## 严重性分级

- **P0**（最高优先级）：捏造权威、意义夸大、挑战与未来公式
- **P1-L**（语言质感 / 词句级）：企业词汇堆砌、四字词语堆叠、翻译腔、过度规整的语法、词的窄效应、泛化表达
- **P1-S**（结构 / 篇章级）：模板化段落、总分总结构、设问式架构、列表对称、连接词脚手架、事件感缺失
- **P2**（语气与节奏）：完美中立、语言风格过稳、强行金句、认知过度完美、社交诱饵结尾

P0 项目必须在输出前修复；P1 项目应当修复；P2 项目视平台和语气而定。

## P0 — 最高优先级

### P0-AUTH：捏造或模糊的权威

检测原则：归因于匿名或泛化主体，且无可验证来源（人名、机构、日期、链接、报告名）。

触发条件：出现 ≥1 次且无具名来源。

| 参考 | 修复 |
|------|------|
| 专家表示 / 业内人士指出 / 业界一致认为 | 指明人名+机构+日期+报告；无来源则删归因并弱化论断 |
| 相关研究表明 / 数据显示 / 据了解 | 指明具体研究或数据出处；无来源则删归因并弱化论断；不要编造引用 |

### P0-HYPE：意义夸大

检测原则：使用拔高性修辞评价事件，但事件本身的具体变化（数字、对比、约束）未被说明。

触发条件：出现 ≥1 次且无对应事实支撑。

| 参考 | 修复 |
|------|------|
| 里程碑式意义 / 划时代 / 开创性 / 革命性 | 说明具体变化：数字、日期、用户数、成本、采用率 |
| 标志着...的到来 / 奠定坚实基础 / 谱写新篇章 | 事件本身普通就让它保持普通；用具体约束替代拔高 |

### P0-FUTURE：挑战与未来公式

检测原则：以口号式展望或平衡修辞收尾，回避具体约束、风险或下一步行动。

触发条件：出现 ≥1 次作为段落或文章收尾。

| 参考 | 修复 |
|------|------|
| 机遇与挑战并存 / 前景十分广阔 / 我们有理由相信 | 指出实际约束条件和下一个决策或风险 |
| 站在新的历史节点 / 在...浪潮下 | 以具体后果结尾，而非口号；指出下一步行动或未解决的问题 |

## P1-L — 语言质感（词句级）

### P1-L-CORP：企业AI词汇堆砌

检测原则：使用包装性动词/名词替代具体动作和事物，删除后不丢失实质信息。

触发条件：同一段落出现 ≥3 个以下类型词汇。

| 参考 | 修复 |
|------|------|
| 赋能、助力、深耕、布局、打造、构建、引领、聚焦 | 用事物本身替代包装性名词 |
| 生态、维度、颗粒度、底层逻辑、顶层设计 | 使用"主体+动作+结果"结构 |
| 全方位、多层次、宽领域、高质量发展 | 不承载实际信息则直接删除 |

### P1-L-FOUR：四字词语堆叠

检测原则：用成语或四字格排比营造气势，但去掉后语义不变或无法指向具体事件。

触发条件：连续 ≥3 个四字词构成排比或并列。

| 参考 | 修复 |
|------|------|
| 蓬勃发展、日新月异、砥砺前行、凝心聚力 | 保留最多一个（若确属作者语域），其余替换为具体事件、数字或平实表述 |
| 守正创新、踔厉奋发、勇毅前行 | 保留最多一个，其余替换为具体事件、数字或平实表述 |

### P1-L-TRANS：翻译腔与僵硬书面语

检测原则：句法骨架源于英文思维（被动前置、长定语从句、抽象名词做主语、介词结构堆砌），用中文词填充英文语法槽位。

**表层模式**（触发条件：同段出现 ≥2 个）：

| 参考 | 修复 |
|------|------|
| 这是一个...的事实 / 可以被认为是 / 作为一种...的方式 | 用自然中文重构：保留谁做了什么、因果和条件 |
| 被...所... / 对于...来说 / 通过...来实现 | 用自然中文重构：去掉被动和冗余介词结构 |

**深层句法骨架**（英文思维的中文表皮；触发条件：同类模式出现 ≥2 处）：

- 物理动作描述思考过程："他将目光转向这个问题""她把注意力放在..."（英文 turn/put/direct 的直译）
- 形容词前置判断："一个令人印象深刻的成就""一种不可忽视的趋势"（英文 an impressive achievement 结构）
- 抽象名词做主语："这种可能性暗示着""该方法的有效性体现在"（中文习惯用人或具体事物做主语）
- 英文逻辑连接词直译："然而""尽管如此""与此同时""在这个背景下"成串出现（中文口语中极少连续使用）

修复：找到句子真正要表达的意思，用"主体+动词+结果"的中文句法重新说一遍。测试：念出声——如果像在读翻译小说，就需要改。

### P1-L-STIFF：过度规整的语法

检测原则：使用空洞副词或冗余连接词填充句式，删除后句意不变。

触发条件：同段出现 ≥2 个以下类型词汇。

| 参考 | 修复 |
|------|------|
| 积极地、有效地、充分地、深入地、全面地、切实地 | 删除空洞副词；仅在真正改变含义时保留 |
| 使得、以至于、鉴于此、有鉴于此 | 简化句式，去掉不必要的书面连接词 |

### P1-L-HEDGE：填充语与叠加式模糊

检测原则：多个不承载信息的提示语或不确定性词叠加，拖慢句子；有事实依据或属于语义锚点的不确定性不算。触发条件：同段出现 ≥2 个，如“需要指出的是”“从某种程度上说”“可能或许”“似乎可以认为”。修复：删除空转提示语；合并重复模糊词，但保留原有断言强度。

### P1-L-NARROW：词的窄效应

检测原则：全文动作词和判断词异常单一，泛化动词、空洞形容词机械重复；核心名词、人名、产品名和有意回环的自然重复不算。

触发条件：满足以下任一项。

| 参考 | 修复 |
|------|------|
| 全文核心动词不超过 5 种（如只有"进行""实现""推动""促进""提升"） | 低于 8 种则替换重复动词为更精确的动作 |
| 同一个泛化动词或空洞形容词机械重复 | 用"某人做了某事"替代"XX得到了有效推进"；不要为了避重而轮换核心名词 |
| 形容词仅用抽象修饰（"有效""显著""重要"），缺乏感官或具象表达 | 素材中已有具体细节则恢复；没有则不补造，改用可验证的动作或后果 |
| 名词全为抽象概念，无一处具体物件、场景或人名 | 替换部分抽象名词为具体物件、场景或人名 |

### P1-L-VAGUE：泛化表达与无场景论断

检测原则：论断缺乏具体对象、动作、后果——换个行业/话题也能成立的万能句。

触发条件：连续 ≥2 段满足以下任一项。

| 参考 | 修复 |
|------|------|
| 大量使用"重要、有效、显著、复杂、关键、值得关注"等抽象判断 | 把抽象判断落到具体对象、动作和后果 |
| 只说"带来提升/产生影响/形成闭环"，不说具体谁受到了什么影响 | 每个核心论点至少补一个具体支撑：事件、数字、动作、限制或真实观察 |
| 连续多个段落没有人物、场景、动作、数字或限制条件 | 每个核心论点至少补一个具体支撑：事件、数字、动作、限制或真实观察 |
| 论点听起来正确，但换到另一个行业也能成立 | 如果没有素材，降低断言强度，不补造案例 |

## P1-S — 结构（篇章级）

### P1-S-TEMPLATE：模板化段落

检测原则：连续段落共享相同的内部骨架（总述→举例→意义），可互换顺序而不影响全文推进。

触发条件：连续 ≥3 段具有相同内部结构。

| 参考 | 修复 |
|------|------|
| 每段先总述，再举例，最后以意义收尾 | 让每个段落承担不同功能：场景、数据、反驳、解释、启示 |
| 各部分可以随意调换顺序而不影响逻辑 | 删除不提供新信息的段落；在论点转折处插入过渡句 |

### P1-S-SANDWICH：总分总结构滥用

检测原则：文章整体呈"提纲→罗列→复述提纲"的教科书式结构，结尾不比开头多出新信息。

触发条件：文章整体呈现"开头宣布→中间罗列→结尾重复"模式。

| 参考 | 修复 |
|------|------|
| 开头宣布主题 | 以具体细节或冲突开头 |
| 中间罗列几个方面 | 如果能制造张力，将论点后移 |
| 结尾重复开头 | 用最终观察、权衡或行动替代总结性收尾 |

### P1-S-RHETORICAL：设问式架构

检测原则：用设问/反问充当段落起手，但问题本身无真正悬念——答案紧跟其后，仅服务于结构而非论证。

触发条件：≥2 个设问句作为段落起点且答案紧跟其后。

| 参考 | 修复 |
|------|------|
| 为什么会这样？/ 那么未来如何？/ 我们该如何看待？ | 除非问题真正开放，否则使用直接陈述 |
| 设问仅服务于结构而非论证 | 仅在能制造真正张力时保留一个问句 |

### P1-S-SYMMETRY：列表对称

检测原则：多个列表项共享完全相同的语法模板，缺乏动词、数字或实例——形式对称掩盖了内容空洞。

触发条件：≥3 个列表项具有完全相同的语法结构。

| 参考 | 修复 |
|------|------|
| 多个列表项具有相同的语法结构 | 转换为散文，或让每项包含动词和具体细节 |
| 每一项都是抽象名词短语，没有动词、数字或实例 | 让每项成为包含动词和具体细节的真实论断 |

### P1-S-SCAFFOLD：连接词和任务分解脚手架

检测原则：用显性连接词（首先/其次/最后/此外）或分类框架（"从X角度"）搭建文章骨架，骨架本身不承载信息。

触发条件：≥4 个显性连接词分布在连续段落开头。

| 参考 | 修复 |
|------|------|
| 高频出现"首先、其次、最后、总之、此外、同时、值得注意的是" | 删除不承载信息的连接词 |
| 用"从X角度来看 / 可以分为几个方面 / 具体来说"搭架子 | 用真实逻辑关系替代：转折、因果、时间推进、场景切换、反例 |
| 每个段落开头都用显性连接词推进 | 用真实逻辑关系替代模板词 |
| 列表项语法完全一致，像任务拆解而不是自然表达 | 指南类可保留列表，但每项必须有动作、场景或判断差异 |

### P1-S-META：机器人残留与空转预告

检测原则：正文保留聊天协作话语、写作预告，或标题后的复述句，却没有增加信息。触发条件：出现 ≥1 处明显机器人残留，或连续 ≥2 处“下面我们来看看”“接下来聊聊”“希望这篇文章对你有帮助”、标题后同义复述。修复：直接进入内容；删除协作残留和空转暖场。

### P1-S-NOEVENT：事件感缺失

检测原则：长篇幅内无具体事件叙事（有主体、动作、结果的场景），全部由修饰性描述和抽象判断填充。

触发条件：连续 800 字以上没有出现具体事件。适用文体：叙事、观点、案例类文章；纯技术文档/政策解读可豁免。

| 参考 | 修复 |
|------|------|
| 段落中无时间、地点、动作三要素 | 每 800 字至少包含一个具体事件（有主体、动作、结果） |
| 描述性修饰多于叙事性推进（"优秀的"多于"他做了"） | 将修饰性段落转化为"前因→动作→后果"的事件链 |
| 全文无一处"谁在什么时候因为什么做了什么"式的叙事句 | 用"那天下午他打开后台看到数据跌了40%"替代"数据出现了显著下降" |

## P2 — 语气与节奏

### P2-NEUTRAL：完美中立

检测原则：个人署名文章中全程无立场、无情感倾向——像百科词条而非有观点的作者。

触发条件：全文无一处个人判断或情感倾向。

| 参考 | 修复 |
|------|------|
| 个人文章中没有立场 | 在平台允许时加入具体的反应 |
| 每句话都保持相同的克制语调 | 仅在真诚时使用第一人称 |
| 情感被抽象地命名，而非通过细节展现 | 让一句话短下来；让另一句话从容展开 |

### P2-FLAT：语言风格过稳

检测原则：连续多段在句长、语气、解释方式上高度一致——缺乏节奏变化和情绪温度波动。

触发条件：连续 ≥3 段相同长度、相同语气、相同解释方式。

| 参考 | 修复 |
|------|------|
| 每段都完整、圆滑、没有停顿或侧重点变化 | 主动制造节奏差：短句、长句、片段句交错 |
| 情绪温度始终一致：一直冷静/温和/笃定 | 让段落承担不同功能：场景、判断、反驳、解释、补充、收束 |
| 没有短句、插入句、转念、局部判断或个人反应 | 允许一两处真实的不确定或保留意见，但不要假装口语化 |

### P2-STACCATO：断句式戏剧与人造金句

检测原则：连续短句或片段句只制造力度，没有推进信息；一个自然的强调短句不算。触发条件：连续 ≥3 句结构相近的短句或无主语片段。修复：合并重复判断，补回真实因果或动作；若符合已解析的作者风格，保留有信息增量的节奏变化。

### P2-CANDOR：假装坦诚式开场

检测原则：用“说实话？”“讲真？”“你有没有发现？”等独立钩子制造亲密感，随后只是普通论断。触发条件：出现 ≥2 处，或单次出现且明显与作者风格、文体不符。修复：直接说出判断；若属于作者样本中的稳定口头禅则保留。

### P2-QUOTE：强行金句

检测原则：出现隐喻式总结句，但隐喻本身未被论证支撑——听起来像名言但经不起追问"具体指什么"。

触发条件：出现 ≥1 个无支撑的隐喻式总结句。

| 参考 | 修复 |
|------|------|
| X 是 Y 的底色/语言/骨架/命脉/注脚 | 问自己：真正的论点是什么？用机制、实例或后果替代隐喻 |
| 句子听起来像引言但缺乏支撑 | 找到隐喻背后的真实论点，用具体机制或后果直接表述 |

### P2-PERFECT：认知过度完美

检测原则：全文无认知盲区、无犹豫、无未解问题——每个反对观点都被轻松化解，呈现超人的认知完备性。只能保留或显化材料中真实存在的认知边界，不得凭空添加疑虑或个人经历。

触发条件：全文满足以下 ≥3 项。

| 参考 | 修复 |
|------|------|
| 文章面面俱到，无一处承认不知道或不确定 | 材料中已有认知边界时保留并说清楚；没有则不补造 |
| 论述无盲区、无"我可能想错了"的自我质疑 | 保留材料中真实存在的未解问题或限制，不制造自我怀疑 |
| 每个论点都有完美支撑，没有悬而未决的问题 | 允许结论停在已有的权衡或未解问题上，不额外编写犹豫 |
| 结论过于圆满，缺乏真人的局限性意识 | 一篇文章中有 1-2 处不确定性即可，不需每段都加 |
| 所有反对观点都被轻松化解，无一例外 | 保留一个真正有力的反对观点，承认其合理性而非强行化解 |

### P2-BAIT：社交诱饵结尾

检测原则：用泛化行动号召（收藏/转发/评论）收尾，但未给出具体理由——为什么值得收藏、讨论什么问题。

触发条件：出现 ≥1 个泛化行动号召。

| 参考 | 修复 |
|------|------|
| 值得收藏 / 建议转发 / 不看后悔 | 给出收藏/转发的具体理由，或直接删除 |
| 看完你就懂了 / 评论区聊聊 | 给出互动的具体理由，或直接删除 |
