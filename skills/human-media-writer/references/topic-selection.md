# 选题工作流

当用户提供宽泛话题、素材或热点但未明确切入角度时，使用本文件执行选题环节。用户已给出具体标题或明确角度时跳过。

本文件分为两部分：

- **第一部分 选题流程（1–6）**：有先后顺序，按编号推进的必经环节。
- **第二部分 思考工具箱（A–E）**：供流程第 3 步"选题思考"调用的原理与框架库，不按顺序执行，按需取用。

---

# 第一部分：选题流程

## 1. 触发规则

无论用户是否已给出角度都执行完整选题流程；

| 模式与场景 | 是否选题 |
|------|------|
| 创建 | 产出 3 个选题方案供用户选定 |
| 改写 | 分析现有选题问题，然后产出 3 个优化选题方案供用户选定 |

用户已给出角度或标题时，将其作为选题输入纳入流程（用工具箱 D 论点检验检验其非共识度并在方案中体现），而非跳过选题。

## 2. 输入诊断

在产出任何选题之前，先声明诊断结论（1-2句）：

- 基于用户提供的哪些关键信息进行选题
- 信息不完整时，基于什么做合理推断

示例："根据您提供的公众号定位和热点素材，我将围绕目标受众的职场焦虑进行选题，因您未指定切入方向，我将基于账号定位推断。"

## 3. 选题思考

诊断完成后，调用第二部分思考工具箱产出候选选题。推荐调用顺序：

- 先用 **工具箱 A（心理学原理）** 校准思考的底层出发点；
- 用 **工具箱 B（战略三问）** 明确为谁、创作什么、为何创作；
- 用 **工具箱 C（战术五要素）** 落地为具体的需求定位、场景、结构、关键词与差异化角度；
- 用 **工具箱 D（论点检验）** 检验并锐化每个角度背后的核心论点；
- 用 **工具箱 E（价值分类）** 标注每个候选交付的价值类型。

A–E 是可调用的框架而非逐条必走的步骤，可根据素材灵活取用。产出候选后进入第 4 步避坑自查。

## 4. 避坑自查

产出选题后，逐条自查：

1. 是否自嗨（脱离用户真实需求）
2. 是否过于宽泛（缺乏具体切入点）
3. 时效是否已过
4. 是否有明确目标用户
5. 是否有钩子和结构
6. 是否有差异化
7. 是否有商业延展性
8. 是否与账号IP一致

命中任何一条，修正后再输出。

## 5. 输出格式

**硬约束**：必须输出 3 个选题方案（不多不少），每个方案严格按下方卡片模板产出，方案末尾不留开放式结尾、不重复任何字段；3 个方案后必须追加横向对比表与一句明确推荐。

采用「决策卡片头 + 方法论依据折叠行」的分层结构：卡片头供用户扫读决策，推理留痕压进最后一行。每个方案如下：

```
### 【选题方案 N】{主标题}

> **核心论点**：大家以为 X，实际是 Y。

- **面向谁**：【用户画像】{用户画像} · 【消费场景】{消费场景}
- **给什么**：{价值类型：实用/情绪/人性} · 命中{痛点/痒点/爽点}
- **爆款潜力**：{高/中高/中} —— {一句理由}
- **备选标题**：
  1. {标题一}
  2. {标题二}
  3. {标题三}
- **方法论依据**：C-5 {切入模型} + D-{n} {检验角度}；结构用 {C-3 模型}；触发 {A 的情感1+情感2}；关键词 {3-5个}
```

字段说明：

- **核心论点**（引用块置顶，方案钩子）：命中工具箱 D 的哪一条检验角度，写出"大家以为 X，实际是 Y"的完整论点句。
- **面向谁**：工具箱 C-2 的用户画像 + 消费场景。
- **给什么**：工具箱 E 的价值类型（实用/情绪/人性）+ 工具箱 C-1 的需求定位（痛点/痒点/爽点）。
- **爆款潜力**：成为爆款的可能性 + 潜在商业价值，一句话说明理由。
- **备选标题**：3 个，体现切入点、包含关键词、呼应情感触发。
- **方法论依据**（推理留痕折叠为一行）：方法论应用（C-5 切入模型 + D 检验角度）、内容结构（C-3 模型）、情感触发策略（A 三原理中的 2-3 种情感）、关键词与标签（3-5 个），用 `;` 分隔。

3 个方案输出后，追加横向对比表与推荐：

```
### 三案横向对比

| 维度 | 方案1 | 方案2 | 方案3 |
|------|-------|-------|-------|
| 价值类型 | … | … | … |
| 命中需求 | … | … | … |
| 差异化角度 | … | … | … |
| 爆款潜力 | … | … | … |

**推荐**：方案 N。理由：{结合当前账号风格 + 平台特性，1-2 句}。
```

## 6. 与后续写作环节的衔接

选题完成后，将用户选定的方案作为输入传递给下一步：

- **创建模式**：选题方案中的"内容结构"直接指导 article-workflow 的正文构建；"目标用户与场景"注入信息收集步骤
- **改写模式**：选题方案中的"核心论点"作为改写的核心论点锚点，替代原文的薄弱角度

# 第二部分：思考工具箱

以下 A–E 为流程第 3 步调用的原理与框架库，不按顺序执行，按需取用。

## A. 心理学原理

所有选题思考从以下心理学原理出发：

### 颠覆常规认知

制造认知冲突。问自己："关于这个主题，99%的人都理解错了什么？"

找到反常识点后，构建"大家以为 X，但实际是 Y"的张力。

### 触发强烈情感共鸣

连接用户内心的核心情感——焦虑、希望、愤怒、怀旧、归属感。让读者产生"太懂我了"的反应。

### 利用关键心理动机

底层动机包括：展示优越感、寻求身份认同、好奇心、对公平正义的追求。在选题中埋下能满足这些动机的钩子。

> 本原理是选题思考的底层出发点：C-5 差异化切入点是"颠覆常规认知"在营销卡位上的落地，D 论点检验是它在论证结构上的落地，两者都可回溯到本节的三原理。

## B. 战略三问（WHO / WHAT / WHY）

每个选题必须清晰回答：

**WHO — 为谁创作？**
- 精准触达核心用户的痛点、痒点或爽点
- 用他们的语言、案例和关注点来检验共鸣度

**WHAT — 创作什么？**
- 提供足够稀缺、优质或颠覆性的核心价值
- 判断属于哪类价值：按工具箱 E 的实用/情绪/人性三分标注

**WHY — 为何创作？**
- 强化而非稀释账号定位和人设
- 服务长期内容战略和商业目标

## C. 战术五要素

### C-1 需求定位

| 类型 | 定义 | 示例 |
|------|------|------|
| 痛点 | 难受、焦虑、痛苦 | "30岁还不会理财，怎么办？" |
| 痒点 | 好奇、向往、渴望 | "普通人如何低成本实现财务自由？" |
| 爽点 | 爽、解压、共鸣、优越 | "老板画的饼，你吃腻了吗？" |

### C-2 角色代入与场景预设

描绘用户画像（年龄、职业、焦虑源）与消费场景（通勤中、睡前、摸鱼时）。

从"缓解焦虑的方法"→ 到"给25岁焦虑女白领的晚间情绪解压指南"。

### C-3 内容结构预设

选题阶段即预判最适合的结构模型：

| 模型 | 核心逻辑 | 适用场景 |
|------|---------|---------|
| AIDA | 注意→兴趣→欲望→行动 | 种草、带货、营销 |
| PBL | 痛点→桥梁→解决方案 | 知识科普、技能教学 |
| STAR | 背景→任务→行动→结果 | 个人经历、案例分析 |
| SCQA | 背景→冲突→疑问→回答 | 行业分析、观点论证 |
| 金字塔 | 结论先行→论据→重申 | 干货知识、效率技巧 |

### C-4 关键词与标签卡位

包含高搜索量、低竞争度、高相关性的关键词组合。

从"健身"→ 到"上班族10分钟居家燃脂（无需器械）"。

### C-5 差异化切入点

核心问题："为什么用户要看你讲这个，而不是别人？"

本要素是 A-颠覆常规认知原理在**营销卡位**上的具体落地（解决"如何包装角度让人想点"），与 D 论点检验的**论证结构**（解决"角度背后论点是否立得住"）互为一体两面。

可用的思维模型：

| 模型 | 转化示例 |
|------|---------|
| 从大到小 | 《如何理财》→《月薪5000，用"4-3-2-1存钱法"一年攒下2万》 |
| 逆向思维 | 《PS技巧》→《我靠这3个PS笨方法，效率超过90%的设计师》 |
| 结合热点 | 《护肤心得》→《深扒热播剧女主角皮肤好的底层护肤逻辑》 |
| 制造冲突 | 《我卸载了30个APP，只留下这3个生产力神器》 |
| 视角独特 | 《谈恋爱花多少钱》→《财务顾问视角：谈一场恋爱的真实成本》 |
| 身份反差 | 《毕业后经历》→《北大硕士送外卖100天，我明白了3个真相》 |
| 数据颠覆 | 《断舍离》→《95%的人搞错了！断舍离的本质不是扔东西》 |
| 形式创新 | 《分析情绪》→《我用Excel做了一份分手情绪分析图》 |
| 深度整合 | 《识别渣男》→《心理学+经济学+玄学，终极渣男识别系统》 |

## D. 论点检验

C 产出候选角度后，用本节检验每个角度背后是否真有论点——不只针对差异化切入点，任何候选选题都要过这一关。相对 C-5 的营销卡位（怎么包装角度让人想点），本节属于论证结构（角度背后的论点逻辑是否立得住）。

依次尝试以下检验角度，命中任何一个即可用它把选题重构为有张力的核心论点（以下为常用角度，可按素材补充新角度）：

1. **反常识点**：这个话题里，大众普遍相信但实际不成立（或过度简化）的认知是什么？
   → 论点结构："大家以为 X，但真正发生的是 Y。"
2. **隐藏代价**：这件事看起来很好，但没人提的成本/副作用/前提条件是什么？
   → 论点结构："X 确实有效，前提是你能承受 Y。"
3. **被忽视的人群**：谁是这个话题中真正受影响但很少发声的角色？
   → 论点结构："当我们讨论 X 时，没人问过 Y 的感受。"
4. **大家知道但没说透的机制**：这件事背后真正起作用的逻辑是什么？
   → 论点结构："X 起作用不是因为表面的 A，而是因为底下的 B。"

如果所有检验角度都无法从素材中找到有力的切入点，说明素材本身缺乏角度——回到信息收集向用户追问立场或经历。

**薄弱 vs 有力的对比**：

| 薄弱（只有主题） | 有力（有论点） |
|------|------|
| "AI 正在改变教育" | "AI 真正改变教育的地方，不是替老师讲课，而是让差生第一次有机会反复问同一个问题。"（角度1：反常识） |
| "普通人如何提升效率" | "效率工具最容易骗到的人，恰恰是最想自律的人。"（角度2：隐藏代价） |
| "小红书运营方法论" | "小红书不是缺内容，而是缺一个能让陌生人立刻代入的场景。"（角度4：没说透的机制） |

用户已给出角度时，用以上检验角度校验它：命中其一则角度成立、锐化其论点结构；全部落空则提示角度偏平并给出重构建议。

## E. 价值分类

每个选题应交付以下一种或多种价值。三分类为唯一标准，括号内为其细分维度：

- **实用价值**：拿来就能用的解决方案、认知工具、决策依据
  - 细分：新知（Information，提供新认知）、技能（Utility，提供可操作方法）
- **情绪价值**：身份认同、焦虑缓解、希望给予、群体归属感
  - 细分：情感共鸣（Emotion）、身份/群体归属
- **人性价值**：好奇心、探索欲、对真善美的追求、对存在意义的探寻
  - 细分：好奇/探索/娱乐（Entertainment）、意义追寻
