# 文章工作流

适用于完整文章创作或大规模重写。

## 1. 加载偏好设置

在向用户提问之前，调用 resolver 获取最小 active profile 配置：

```bash
python3 skills/human-media-writer/scripts/resolve_preferences.py \
  --workspace-dir "{workspace_dir}" \
  [--profile "<name>"]
```

resolver 内部优先读取项目级 `{workspace_dir}/.human-media-writer/EXTEND.md`，再读取用户级 `$HOME/.human-media-writer/EXTEND.md`。只使用脚本返回的 active profile、风格、长度和审核参数；不要直接读取完整 EXTEND.md。

## 2. 信息收集

明确以下内容：

- 发布平台
- 目标读者
- 主题
- 期望立场
- 可用素材
- 发布目标
- 禁止的主张或敏感边界

如果关键信息缺失，提出一两个有针对性的问题。如果用户追求速度，则基于明确的假设继续推进。

## 3. 委派选题子代理

委派选题子代理 `references/topic-selection-prompt.md` 进行选题

传入参数：

- `[MATERIAL]`：用户提供的话题、素材、笔记、转录稿、背景信息
- `[CANDIDATE_TOPIC]`：用户已给出的标题、角度或想写方向；如果没有则留空
- `[PROFILE_CONTEXT]`：active profile 中的 `positioning`、`audience`、`purpose`；没有则填"（空）"
- `[MODE]`：`article`

主代理直接呈现子代理返回的三个主题方案，等待用户选定；随后，将用户所选方案中的关键信息提取并注入后续步骤：
- "目标用户与场景" → 补充信息收集中的目标读者
- "内容结构" → 指导第9步正文构建
- "核心论点" → 作为第7步核心论点的起点
- "关键词与标签" → 指导标题和SEO优化

## 4. 语义锚点

写作前，从素材中提取以下信息并在内部标记为不可改变的锚点：

- 名称、人名、机构名、产品名
- 日期、时间线和事件顺序
- 数字、价格、比例、排名
- 因果主张
- 对比关系
- 引述性陈述
- 否定、限制条件和极性（正面/负面立场）
- 不确定性标记（"可能"、"据说"、"目前来看"）
- 用户提供的个人经历
- 明确的情感倾向和价值判断

如果某个主张缺乏支撑，在内部标记为弱论据。以适当的不确定性来写，或直接省略。Never 为了让文章更像真人而补造证据。

## 5. 风格

按优先级确定写作风格：

1. 用户本次请求中的显式风格指令（最高优先）
2. resolver 返回的 active profile `custom_style`（内联自定义风格）
3. resolver 返回的 active profile `writing_style`（内置风格预设名）
4. `default` 风格预设（兜底）

使用 resolver 返回的 `style` 获取具体声音参数（措辞习惯、节奏偏好、情感范围、开头方式、结尾偏好）。若用户提供了写作样本要求模仿，或需要从样本提取风格结构，按 SKILL.md §写作风格系统 的自定义风格结构与样本提取流程执行。

## 6. 平台

从用户信号中确定目标平台：

| 信号 | 平台 |
|------|------|
| 公众号/微信/长文/深度 | 微信 |
| 小红书/xhs/笔记/种草 | 小红书 |
| 无信号 | resolver 返回的 active profile `platform`，再无则默认微信 |

确定后按 SKILL.md §平台形态 应用对应约束（段落长度上限、开篇模式、内容密度要求、读者注意力模型）。

## 7. 选择开头方式

优先使用风格文件中的 `preferred_opening`。如果内容需要其他方式，可以覆盖。

可选方式：

- 场景：一个具体时刻或用户情境
- 矛盾：普遍认知与实际发生的情况之间的冲突
- 数据：令人惊讶的数字，但要解释它为什么重要
- 坦白："我以前也以为……"
- 问题："很多人卡在……"

避免：

- "随着时代发展……"
- "在当今社会……"
- "近年来，……受到广泛关注"

## 8. 构建正文

每个段落应承担不同的功能：

- 解释机制
- 展示案例
- 比较替代方案
- 指明利弊权衡
- 回应可能的质疑
- 给出一个可操作的方法

不要让每个段落都变成"观点 + 解释 + 意义"的套路。

## 9. 增加质感

只使用服务于论点的质感素材：

- 用户提供的小趣闻
- 一个实操细节
- 一个现实中的质疑
- 一句承认不确定性的表述
- 一句冷幽默

## 10. 结尾

好的结尾：

- 带着新的意义回到开篇场景
- 诚实地指出利弊权衡
- 给出一个具体的下一步行动
- 留给读者一个精确的问题

糟糕的结尾：

- "未来可期"
- "让我们共同期待"
- "总之，这是一个值得关注的方向"
- "希望本文对你有所帮助"

参考风格文件中的 `ending_style` 确定收尾偏好。

## 11. 委派审核子代理

文章起草完成后，按 `references/reviewer-workflow.md` 的「审核子代理模板」派发独立子代理进行 AI 痕迹审核，然后按其「迭代修订协议」执行修复→再审循环，直到满足终止条件。
