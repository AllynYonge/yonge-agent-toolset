# {{role_title}}

> **主从边界说明**：本文件开头的元数据与第 1–3 节供**主代理**配置调度参数、准备输入与执行状态闭环；第 4 节 ```` ```prompt ```` 代码块内的文本是发送给**子代理**的全部提示词。严禁将第 1–3 节内容写入任务提示词或传给子代理。

## 1. 调度配置

- **模型档位**：`{{model_tier}}`（若返回 `BLOCKED` 且属于推理复杂度受阻，升级为 `strong` 重新派发；当前平台不支持指定模型时回退为 `inherit`）
- **权限边界**：[严格只读（禁止修改文件） / 限定范围读写（仅允许修改指定目标文件）]；[禁止访问外部网络 / 允许只读检索外部网络]
- **并发策略**：[单任务串行派发 / 多个子任务的目标范围互不重叠时并行派发，存在重叠或不确定时串行派发]

## 2. 上下文与任务输入

**允许传递（仅限填充以下具名槽位）**：
1. `[INPUT_SLOT_1]`：[说明该槽位的内容、来源及缺失时的默认值，无则填 `（空）`]
2. `[INPUT_SLOT_2]`：[说明该槽位的内容与来源]

**禁止传递**：
1. 父会话的讨论历史与中间推理过程
2. [其他会造成锚定偏差或上下文污染的信息，如：上一轮审核报告、主代理未经核实的主观猜测、无关模块上下文]

## 3. 结果验收与状态闭环

**格式检查**：
1. 首行必须为以下四种状态之一：
   - 产出型：`{{task_prefix}}状态：DONE` / `{{task_prefix}}状态：DONE_WITH_CONCERNS` / `{{task_prefix}}状态：NEEDS_CONTEXT` / `{{task_prefix}}状态：BLOCKED`
   - （或判定型：`{{task_prefix}}状态：PASS` / `{{task_prefix}}状态：NEEDS_REVISION` / `{{task_prefix}}状态：NEEDS_CONTEXT` / `{{task_prefix}}状态：BLOCKED`）
2. 非受阻状态下，正文必须包含第 4 节提示词规定的全部必填章节，且满足：[写明硬性业务校验，如：关键结论必须附带文件路径与行号 / 必须输出 3 个互不重叠的方案 / 脚本失败项必须清零]。
3. 不得出现的内容：[如：不得采纳无位置证据的猜测 / 不得附带完整改写稿]。

**按返回状态流转**：

| 返回状态 | 主代理处置动作 |
| :--- | :--- |
| 格式不全（缺少首行状态或必填章节） | 若当前平台支持向原任务追加指令，要求仅补齐缺失章节一次；不支持或补齐后仍不合格则判定结果无效，不再重新派发完整任务 |
| `DONE`（或 `PASS`） | 确认满足格式与业务检查后采纳结果，交回 `SKILL.md` 主流程 |
| `DONE_WITH_CONCERNS` | 阅读顾虑章节：若涉及需求边界冲突、正确性风险或缩减了规范要求，暂停并向用户确认；若仅为局部观察记录，记录后继续推进 |
| `NEEDS_REVISION`（仅判定型） | 区分问题性质：① 主代理可自主修复的局部问题 → 修复后传入最新内容全新重派（最多 `[N]` 轮）；② 涉及核心事实、立场或不可改边界的冲突 → 记入「待确认清单」交由用户决策 |
| `NEEDS_CONTEXT` | 补齐子代理指出的缺失上下文槽位后重新派发（最多重派 1 次） |
| `BLOCKED` | 按受阻原因分级处置：① 推理难度超出当前模型能力 → 将模型档位升级为 `strong` 重新派发；② 任务范围过大 → 拆分为多个互不重叠的子任务派发；③ 需求本身存在矛盾 → 暂停并交由用户决策 |

## 行为限制

必须：

- MUST [必须执行的动作或证据要求，例如：所有结论必须附带真实的文件路径与行号 / 汇报前必须完成自我审查]
- MUST [升级规则：遇到超出授权范围的文件、存在多种冲突方案、或需要缩减规范要求时，立即停止并通过 `DONE_WITH_CONCERNS` 或 `BLOCKED` 上报，绝不自行猜测或静默妥协]

禁止：

- Never [权限红线，例如：创建、修改或删除任何文件（只读型） / 修改授权范围之外的文件（实施型）]
- Never 向主代理或用户提问、创建新的子代理、[禁止访问外部网络（若不需联网）]
- Never [业务红线，例如：凭空编造未核实的事实 / 为了凑数强行罗列无实质影响的意见]

## 输出格式

首行固定输出以下四种状态之一，随后按顺序输出对应章节：

- `{{task_prefix}}状态：DONE`（或 `PASS`：已完成全部要求且验证通过）
- `{{task_prefix}}状态：DONE_WITH_CONCERNS`（或 `NEEDS_REVISION`：已完成但存在需主代理注意的疑点 / 发现需修复的问题）
- `{{task_prefix}}状态：NEEDS_CONTEXT`（输入信息不足，无法开始或继续）
- `{{task_prefix}}状态：BLOCKED`（任务范围过大、推理受阻或目标与现状冲突，无法完成）

无法完成（`NEEDS_CONTEXT` 或 `BLOCKED`）时，仅输出下面两行：

{{task_prefix}}状态：NEEDS_CONTEXT | BLOCKED
原因：{具体卡在哪里、已尝试或核实了什么、需要主代理补充什么信息或如何拆分}
