# 「风格」属性

发布页「类目属性 → 其他属性」里的多选字段，**最多 5 项**。非必填，但空着会拉低商品质量分。

三件事要分清：

| | 谁决定 | 怎么处理 |
|---|---|---|
| **有哪些可选值** | 平台，随类目变 | **默认运行时自动**：`getStyleCandidates` 开下拉虚拟滚动收集当前真实全集；文档快照仅作手动传参时的对照 |
| **这一款该选哪几个** | 看主图判断 | **默认 pi 自动**：`pickViaPi` 一次调用同时返回风格+热搜词；也可 `--styles` 手动传 |
| **结果校验** | 脚本 | pi/手动的值都会过滤到候选集内，候选外的值不会出现在页面上 |

## 怎么根据图片选（手动路径 / pi 提示词同源规则）

读 `<素材目录>/<款号>/主图01.*`（必要时加看 `参考图/`）判断。

**选 2-4 项**：1 项覆盖不足；贴满 5 项会稀释标签精度，让平台分不清主要风格。

判断不了时**宁可少选**：选错的风格标签比不填更伤 —— 它会把商品推给不匹配的人群。
拿不准就只留真万无一失的那一两项，或把图拿给用户确认。

传了当前类目没有的值只打警告、不阻断，日志会把该类目实际可选项一并列出，
照着改即可（常见是漏字，如「轻熟」应为「轻熟风」）。超过 5 项只取前 5 项并上报舍弃的。
