# 排障详表

SKILL.md「排障」节列的是高频项，本文是全量对照表。
正文没命中时按现象在这里查；涉及 DOM 定位的项一律配合
[dom-notes.md](dom-notes.md) 一起看。

## 浏览器与连接

| 现象 | 原因 / 处理 |
|------|------------|
| `未检测到已开启调试端口的浏览器` | 浏览器没开调试端口，或 `cdp-proxy.mjs` 占着端点（先 `pkill -f cdp-proxy.mjs`） |
| 浏览器整体卡死、DevTools 端口不响应 | 关标签页时弹了原生「离开站点？」框。`Page.close()` 已做双保险；若仍出现，手动点掉弹窗 |
| 反复弹「Allow remote debugging?」 | 用 `--launch`（隔离 profile 实测不弹）。若坚持用 `--port` 连日常浏览器，点一次 Allow 后地址会被缓存 |
| 怀疑连错了浏览器 | 看 `<profile>/devtools-ws.json` 里的 `pid`/`port` 是否与 `chrome.pid` 一致；不一致会被自动拒绝 |
| 专用浏览器起不来 | 看 `~/.yonge/doudian/chrome-profile/chrome-err.log` |

## 登录

| 现象 | 原因 / 处理 |
|------|------------|
| `等待登录超时` | 用户没在时限内登录完。登录后重跑，或用 `--login-timeout` 加长 |
| 明明登录了却报未登录 | 登录探针指向了 `https://fxg.jinritemai.com/`（对外招商官网，登录与否都能打开）。探针必须打 `/ffa/...` 这类需鉴权路径 |

## 模板与素材

| 现象 | 原因 / 处理 |
|------|------------|
| `模板缺少必需列: 参考图` | 0.4.0 新增的必填列。旧模板补上这一列，或用 `make-template.py` 重新生成 |
| 插了参考图却报「缺少参考图」 | 若单元格内容是 WPS `DISPIMG(...)`，脚本会从 `cellimages.xml` 恢复；若仍失败，可能是图片关系缺失或 Excel 365 `IMAGE()` 外部公式没有本地二进制。改用传统「浮动图片」或填写本地文件路径 |

## 页面渲染与表单填写

| 现象 | 原因 / 处理 |
|------|------------|
| `等待超时: 发布页首图上传控件` | SPA 没渲染完。已用 `waitRendered` 处理；仍失败则查是否被风控跳转（未登录已由前置检验拦住） |
| `等待超时: 材质搜索框` | 下拉没开。真实鼠标点击与 JS 事件派发各自都会偶发失效，脚本两种交替重试 4 次 |
| `等待超时: 品牌搜索结果（xxx）` | 新版智能填写把品牌预填成「无品牌」，placeholder「请输入需要关联的品牌」随之消失，老选择器定位不到。已于 2026-08-31 改为「品牌」标签兄弟容器定位 + `clickReal` 展开 |
| 草稿里主图只剩 1 张，但日志说传了 4 张 | 辅助图的等待判据太松：图片选中即渲染 `img`，只数 img 会在上传完成前就通过，接着点确认就把未完成的丢了。已改为「只数 src 已落 CDN 的图 + 连续采样稳定 + 跳转后二次校对并补传」。见 [dom-notes.md](dom-notes.md)「辅助图（主图02-05）在这一页传」 |
| `file input 不存在: div.material-upload-button input[type=file]` | 确认页的「确认信息，继续生成」比辅助图槽位先挂载，上传前需先等槽位渲染（已内置） |
| 草稿报「面料材质该项为必填」或「含量必须全填写或全不填写，且材质不能重复」 | 智能填写预填了一条不带含量的材质（实测「新型聚酯纤维」），与脚本追加的并存。`setFabric` 现在会先清空预填项再写 |
| SKU 行数多一组（多出「杏色」「米白色」这类没填过的规格） | 智能填写从主图猜了一个颜色占行，它既无价格也无规格图，会连带报「价格为必填」+「请上传规格图」。`removePrefilledSpecValues` 会在追加完后删掉不在模板里的值 |
| `品牌未找到` / `未找到模板，可选: `（可选项为空） | 用 `waitDropdownOptions` 等选项真的出现后才读。若报错且可选项非空，就是模板名真的不对 |
| 日志里出现「AI 推荐不可用，回退手填标题」 | AI 推荐接口本次未返回（已内置重试 1 次）。不阻断，会用 Excel「商品标题」列 + 手动选类目完成。偶发可忽略；持续出现跑 `node scripts/doctor.mjs --image <1:1 主图>` 看「AI 标题路径」一行 |
| 自动填充的类目不是想要的 | 当前约定以平台识别为准，只打警告不覆写。需要强制走 Excel 类目请说一声，这是个行为开关 |
| 「导购短标题 AI 未返回，跳过」 | 平台 AI 接口本次没出结果（已重试 1 次）。非必填，不阻断；介意就人工补一下 |
| 日志里出现「当前类目无此风格」 | `--styles` 传的值不在该类目的选项里。只警告不阻断，紧跟的一行会列出该类目实际可选项（常见是漏字，如「轻熟」应为「轻熟风」） |
| 发货时间/库存计数没改动 | 这两项是 radio，靠标签文案锁区域后再匹配选项。已是目标值时不重复点（日志照样打出值）。报「XX 无此选项」是写法不对，看报错里列的可选项；报「字段不存在，已跳过」则是该类目没这个字段。见 dom-notes「四组同构的 radio」 |

## 规格与 SKU

| 现象 | 原因 / 处理 |
|------|------------|
| `规格值写入失败` | 六步序列被打断，见 dom-notes「新建规格值」 |
| `规格值写入失败: XX（当前: ）`、`尺码写入规格区失败（当前: 无）` | 括号里是空的 = 读得太早。这两处走轮询等待；若仍出现说明真的没写进去 |
| 尺码报 `Cannot read properties of undefined` | 尺码面板有两种随机切换的视图，其中一种没有 ul/li。定位方式是「checkbox + 往上找短文案」，两种都兼容。日志会打印「尺码面板视图 A/B」 |
| `SKU 行数不匹配: 页面 3 行，预期 12 行` | 尺码没选上（只有规格值维度）。`setSizes` 会校验并抛错，若仍出现看 dom-notes「尺码」节 |
| `SKU 行数不匹配: 页面 10 行（或 13 行），预期 12 行` | 行高取错。`thead` 表头行里有「批量传图」的 file input，会被当成数据行取到（表头 67px vs 数据行 73px），导致全局下标碰撞。行高必须限定在 tbody 内取，见 dom-notes |
| 价格/库存串行 | SKU 表行顺序 = 页面实际规格值顺序，与 Excel 顺序可能相反。脚本按页面顺序读，若改过这段先看 dom-notes |
| `以下 SKU 行未填写` | 虚拟表滚动步长没覆盖到全部行，看报错里列出的规格-尺码 |

## 校验与提交

| 现象 | 原因 / 处理 |
|------|------------|
| 草稿被「请输入水洗标/吊牌图」之类卡住 | 那是发布级要求。`--mode draft` 跳过「填写检查」直接存草稿 |
| 校验报「需上传完整尺码表信息」 | 「尺码表模板」列填抖店已存的模板名 |

## 性能

| 现象 | 原因 / 处理 |
|------|------------|
| 耗时比以前长 | 预期行为。`sleep()` 带 [0.8, 1.75) 随机抖动（拟人），期望值约 1.27 倍，单款约 4 分钟。调试时可用 `DOUDIAN_NO_JITTER=1` 关掉 |
| 大量 `等待超时` / 选择器找不到 | 抖店可能改版了。跑 `node {baseDir}/scripts/doctor.mjs --launch` 体检，命中兜底或失效的项去更新 `scripts/selectors.mjs` |
